CRIMEFILE / CASE 002 / DIGITAL EXHIBIT 01

Restricted Archive Lock

Four digits protect the first technical exhibit. Enter a four-digit attempt and use the feedback to crack the lock. You have eight attempts per round.

X = correct digit, correct position O = correct digit, wrong position — = digit not in code

Case note: feedback counts duplicate digits correctly. The order of the feedback marks does not correspond to the order of your guessed digits.
